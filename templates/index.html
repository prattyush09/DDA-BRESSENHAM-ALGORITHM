📈 Line Rasterization

DDA Line Algorithm

Digital Differential Analyzer calculates intermediate pixel positions incrementally using calculated X and Y step increments based on line slope.

Key Concept: Floating point increments & rounding Formula: ΔX = dx/steps, ΔY = dy/steps
⭕ Circle Rasterization

Bresenham Circle Algorithm

Integer-based circle generation visualizer utilizing decision parameters (P = 3 - 2r) and 8-way circular symmetry for zero floating-point overhead.

Key Concept: 8-Way Symmetry & Integer Math Formula: P0 = 3 - 2r
